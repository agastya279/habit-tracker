# Habit Tracker

A small desktop habit tracker built with Python's standard-library Tkinter GUI. It uses a dark-blue palette and saves your habits locally.

## Features
- Add and remove habits
- Mark a habit complete for today
- See each habit's current streak, last completion date, and today's status
- Save data in `habits.json` beside the application

## Run
Python 3 with Tkinter is required (Tkinter is included with most Python installations).

```bash
python habit_tracker.py
```

On some Linux distributions, install the Tkinter package first (for example, `python3-tk`).

The repository is named `habit-tracker` because GitHub repository names cannot contain spaces.
